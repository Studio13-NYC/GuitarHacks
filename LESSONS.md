# Lesson plug-ins

Add a UTF-8 `.json` file to `lessons` beside GuitarHacks.exe. Open and close Connection, or restart the app, to reload it. Invalid files appear as lesson errors; valid files continue to load. The app copies missing bundled files on launch and preserves existing lesson files.

Example: `my-c-practice.json`

```json
{
  "version": 1,
  "id": "my-c-practice",
  "title": "C on the A string",
  "description": "Find C, then connect the sound to its position.",
  "cards": [
    {
      "id": "c-a3",
      "prompt": "Play C\non the A string",
      "instruction": "String 5. Find it between frets 1–12. Do not use the open string.",
      "hint": "A string, fret 3 · C3",
      "midi": 48,
      "string": 5,
      "match": "exact"
    }
  ]
}
```

## Contract

- `version`: 1.
- `id`: unique across lesson files. Use lowercase letters, digits, hyphens and underscores; start with a letter or digit; maximum 80 characters.
- `title`: 1–80 characters, shown in the lesson selector.
- `description`: 1–500 characters.
- `cards`: 1–5,000 cards. Maximum file size 2,000,000 bytes.
- Card `id`: same identifier rules; unique within its lesson.
- `prompt`: 1–80 characters; short text reads best at distance.
- `instruction`: 1–240 characters; state the string or other constraint.
- `hint`: 1–500 characters, revealed on request.
- `midi`: integer 40–76 inclusive (E2–E5). Middle C is 60. The answer must be expressible as one pitch.
- `string`: optional integer 1–6 (1 = thinnest/high E, 6 = thickest/low E). Uses this string's measured open-pitch reference when judging the answer. Without it, the median tuning offset across all six strings is used.
- `match`: `exact` (default) requires the specified octave; `pitch_class` accepts that note in any supported octave.

A prompt's spelling is independent of its sounding pitch, so C-sharp and D-flat both use the same MIDI number. Authors must provide musically consistent instructions and answers; validation checks the file format, not arbitrary musical prose. Audio cannot verify a requested fret, string or finger.

Lesson IDs, card IDs, match mode and target pitch identify progress. Keep those unchanged to retain a card's history. Change a card ID when changing the skill it teaches. Duplicate lesson IDs cause the later file in filename order to be rejected.

## Shared behavior

At Start, the core measures background and asks for six open strings; setup is unscored. Lesson answers use these measured references with ±25 cents tolerance. Lessons do not manage hardware, open microphones, process audio, or write progress directly. The core selects an input once, validates stable notes, waits for a fresh mute, judges the target, saves outcomes, and chooses a weighted 12-card set. All lessons inherit saved time/attempt limits, countdown, attempt counting, Quit, weighted review, large text and full-screen mode. The hint field is retained for compatibility but the minimal card screen does not reveal hints.

This version supports declarative single-note lessons. It does not load executable plug-in code, accept simultaneous chords, infer finger position, or schedule calendar-based reviews. Add new JSON files for more note or interval drills; a different response type requires an explicit extension to the core.

Write the prompt as an action with its string, such as "Play C\non the A string". Use the instruction to specify the permitted region and whether open strings are allowed. Say "one octave above" explicitly when needed; do not rely on a pitch number alone. Keep the exact answer fret in the hint. Calibration is separate and explicitly supplies fret 0 for each open string.

All lessons share a one-second result hold followed by a two-second asterisk transition. Audio is ignored during both; listening resets and requires a fresh mute. The optional success sound is controlled in Connection. Wrong notes flash red and allow retries until the saved time or attempt limit is reached. A third correct attempt is accepted when the limit is three. The countdown starts when the new target is shown. Only the asterisk screen shows total run time and cards remaining.

The four built-in exercise modes are generated by `exercises.py` with shared `fretboard-v2` identities. Choosing a JSON lesson disables those four mode filters. For string-specific plug-ins the card screen shows the prompt above the named string, with an octave-up marker when the target is at least 12 frets above open. The original instruction remains in the stored card label; arbitrary instructional prose is not shown alongside the minimal string-specific card. Cards without string metadata show their instruction below the prompt.
